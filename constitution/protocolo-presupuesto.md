# Protocolo de Reasignación Presupuestaria

Obligación diaria de los 3 ministros además de las propuestas normativas.

## Formato (se añade al final del fichero de propuestas del día)

```markdown
## Reasignación presupuestaria — YYYY-MM-DD
- **Programa/ línea de gasto analizada**: (nombre y partida si consta; fuente: PGE, IGAE, noticia)
- **Situación actual**: (€ aproximado, qué consigue, qué falla — CON DATO)
- **Problema detectado**: (dónde el dinero no llega o sobra, con evidencia)
- **Propuesta de reasignación**: de X € → a Y €, destino concreto
- **Justificación de peso**: (impacto esperado, indicador de éxito medible, plazo)
- **Fuente**: (URL/noticia/dato INE-IGAE o marcado como estimación)
```

## Reglas
1. **Toda cifra con fuente** o marcada explícitamente como estimación. Cifra sin fuente → la rechaza el Auditor.
2. El dinero se manda **donde hay problema medido**, no donde hay ruido mediático. La noticia activa la hipótesis; el dato la confirma.
3. Prioriza eliminar gasto ineficiente antes de pedir gasto nuevo.
4. Indicador de éxito obligatorio: si no se puede medir si funcionó, la reasignación no va a Consejo.
5. El Auditor audita estas propuestas igual que las normativas: `VALIDADA / VALIDADA CON OBSERVACIONES / RECHAZADA`.
